# Быстрый старт с Agent Relay

[Обзор](../README.ru.md) · [English guide](guide.md) · [Последний релиз](https://github.com/korzhy/agent-relay-downloads/releases/latest)

## Перед установкой

- **Windows 10 или 11, x64.** Установщик Relay включает .NET и устанавливает приложение для текущего пользователя Windows без прав администратора.
- **Codex для Windows.** Войдите в настольное приложение OpenAI и откройте Codex. Первую задачу запустите из чата в своём проекте. [Инструкция OpenAI для Windows](https://learn.chatgpt.com/docs/windows/windows-app#download-the-chatgpt-desktop-app)
- **Antigravity CLI (`agy`).** Установите его под тем же пользователем Windows. Понадобится аккаунт Google с доступом к моделям и свободной квотой. Окно Antigravity можно оставить закрытым. [Установка Antigravity CLI](https://antigravity.google/docs/getting-started?tab=cli)
- **Учебный репозиторий.** Для первого запуска возьмите Git-репозиторий с вымышленными данными. В нём удобно посмотреть изменения и при необходимости отменить их.

## Проверка установщика

На [странице последнего релиза](https://github.com/korzhy/agent-relay-downloads/releases/latest) скачайте `AgentRelaySetup-x64.exe` и `AgentRelaySetup-x64.exe.sha256` из одного релиза. Если нужен только установщик, воспользуйтесь [прямой ссылкой](https://github.com/korzhy/agent-relay-downloads/releases/latest/download/AgentRelaySetup-x64.exe).

В Проводнике откройте папку с двумя файлами, введите `powershell` в адресную строку, нажмите Enter и выполните:

```powershell
$expected = ((Get-Content -LiteralPath '.\AgentRelaySetup-x64.exe.sha256' -Raw).Trim() -split '\s+')[0]
$actual = (Get-FileHash -LiteralPath '.\AgentRelaySetup-x64.exe' -Algorithm SHA256).Hash
if ($expected -match '\A[0-9a-f]{64}\z' -and $actual -eq $expected) {
    'SHA-256 совпадает'
} else {
    'SHA-256 не совпадает. Не запускайте установщик.'
}
```

Установщик пока не подписан. Windows может показать предупреждение SmartScreen или сообщить, что издатель неизвестен. Совпадение SHA-256 подтверждает, что скачанный файл соответствует контрольной сумме на GitHub. Контрольная сумма не подтверждает личность издателя и не заменяет цифровую подпись.

## Настройка и первая задача

1. **Установите и откройте Relay.** Запустите проверенный установщик под своим обычным пользователем Windows и откройте Agent Relay из меню «Пуск». Создайте новый чат Codex, чтобы он прочитал установленные Relay инструкции.
2. **Подключите аккаунт Google.** В Relay откройте **Аккаунты**, задайте понятную вам метку и нажмите **Добавить аккаунт**. Завершите вход в браузере и выберите этот аккаунт в Relay. По кнопке состояния откроется **Диагностика**, где можно проверить готовность обоих инструментов.
3. **Выберите, когда передавать задачи.** Для первого запуска включите режим **Обычный** с одним исполнителем. **Точечно** подходит для простой механической работы. **Баланс** позволяет рассматривать и более сложные задачи с ясным результатом и проверкой. **Активно** предлагает Codex чаще искать подходящие задачи для передачи. **Выкл.** отключает внешнего исполнителя.
4. **Откройте новый чат Codex в учебном репозитории.** Задайте конкретные правки и способ их проверки. Если Codex сообщит, что Relay требует доверия, проверьте точный путь и разрешите Codex выдать доверие для этой папки. На время пробы оставьте Auto-approve выключенным. С ним Relay доверяет подходящим новым папкам без отдельного подтверждения. Выключение настройки сохраняет ранее выданные разрешения.
5. **Вернитесь за результатом в тот же чат.** Когда Relay покажет, что отчёт готов, попросите Codex забрать его из очереди отчётов Relay, посмотреть изменения и выполнить согласованную проверку перед интеграцией.

Сохраните в Git три текстовых файла в папке `samples`. В каждом перемешайте вымышленные имена в нижнем регистре, по одному на строку. Напишите в Codex:

> Оцени, подходит ли для Agent Relay сортировка строк по алфавиту в каждом текстовом файле папки `samples/`. Разреши менять только эти файлы. Если делегируешь, получи отчёт в этом чате и сам проверь, что каждый список отсортирован и содержит ровно те же строки, что и раньше.

Codex может выполнить задачу сам, если её передача займёт больше времени.

### Выбор модели исполнителя

По умолчанию Relay использует **Hydrogen High**. Ему можно поручить работу в нескольких файлах, если Codex понимает подход и может проверить результат. Например, попросите Codex передать Hydrogen добавление нового поля в импорт CSV вместе с обновлением проверки данных и тестом на совместимость со старыми файлами.

В разделе **Исполнитель** можно выбрать **Flash High** или задать Hydrogen одно из доступных усилий. С версии 0.5.22 режим **Авто** позволяет Codex выбрать **Low** для простой механики, **Medium** для рутинной работы с исключениями или **High** для сложной задачи. Если усилие в задаче не указано, используется High. **XHigh** можно выбрать вручную.

Нажмите **Сохранить выбор**, чтобы применить настройку к новым задачам. Порог определяет, в каких случаях Codex рассматривает передачу. Усилие задаёт глубину работы Hydrogen над конкретной задачей.

## Парный режим и локальные данные

- **Парный** режим включается по желанию. Через **Настроить второго** укажите второго существующего стандартного пользователя Windows. В обоих профилях нужны одна версия Relay и рабочий доступ к Antigravity. Для создания отдельных рабочих копий уже доверенных проектов требуется явное разрешение. Codex запускает в этих копиях независимые задачи и интегрирует результаты по очереди. Начиная с 0.5.21, готовый отчёт освобождает место для следующей задачи, пока ожидает проверки.
- Relay хранит настройки, доверие к папкам, историю передач, отчёты и диагностику локально на ПК. Учётные данные Google, которыми управляет Relay, сохраняются в диспетчере учётных данных Windows. При делегировании исполнитель Antigravity получает текст задачи и нужные для неё файлы проекта. Перед передачей проверьте, что именно ему разрешено читать и менять.

## Обновление Relay

Начиная с 0.5.19, Relay предлагает доступное обновление в главном окне. Нажмите **Обновить**. Relay скачает и проверит файл, установит обновление и перезапустится. Проверка наличия новой версии сама по себе ничего не устанавливает. Если Relay сообщает об активной задаче, дождитесь завершения и нажмите кнопку снова.

Для ручного обновления запустите проверенный установщик последней версии под тем же пользователем Windows. Этот способ подходит и для версий до 0.5.4 включительно, которые проверяют обновления по старому адресу. В парном режиме обновите оба профиля до одной версии. После обновления или восстановления интеграции откройте новый чат Codex, чтобы загрузить свежие инструкции.

## Если что-то не работает

| Что происходит | Что проверить |
| --- | --- |
| Relay не находит Codex или `agy` | Откройте **Диагностику** и посмотрите **Readiness**. Установите оба инструмента для пользователя Windows, запустившего Relay. Откройте Codex и проверьте, что `agy --version` работает в новом терминале. |
| Codex не рассматривает передачу | Откройте новый чат, проверьте порог делегирования, доверие к папке и наличие у задачи чётких границ и проверки. Если интеграция отсутствует, нажмите **Восстановить интеграцию Codex** в диагностике и откройте новый чат. |
| Аккаунт не может выполнить задачу | Проверьте активный аккаунт и квоту в **Аккаунтах**. Убедитесь, что команда `agy models` показывает подходящую модель. |
| Отчёт готов, а Codex бездействует | Вернитесь в чат, откуда запустили задачу, и попросите забрать отчёт из очереди Relay. Перед интеграцией проверьте результат. |
| В 0.5.19 парный режим постоянно занят | Немного подождите и попросите Codex перепроверить ту же задачу. Если окно состояния продолжает мешать, выберите **Exit** в меню значка Relay в области уведомлений. Снова откройте Relay, когда Codex закончит проверку статуса. Запущенные исполнители продолжат работу. |
| Попытка завершилась без подтверждённого отчёта | Попросите Codex проверить состояние попытки и частичные изменения перед повторным запуском. Ограничения конкретной версии описаны в [заметках к релизам](https://github.com/korzhy/agent-relay-downloads/releases). |

У репозитория загрузок пока нет открытого трекера поддержки. Если у вас уже есть способ связаться с автором, укажите версию Relay и Windows, шаг, на котором возникла проблема, и короткое сообщение об ошибке. Удалите сведения об аккаунтах, локальные пути и содержимое проекта. Полные журналы оставьте у себя.
